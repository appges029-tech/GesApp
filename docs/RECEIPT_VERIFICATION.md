# Vérification d’authenticité des reçus

GesApp 1.4.1+16 ajoute **Finances > Vérifier un reçu**.

- recherche exacte du numéro, insensible à la casse ;
- distinction reçu valide / authentique mais annulé / introuvable ;
- détails du paiement, remboursements, année scolaire, référence et affectations ;
- fonctionnement 100 % hors ligne ;
- aucun changement du schéma SQLite.

La vérification atteste l’existence du reçu dans la base GesApp présente sur l’appareil.
